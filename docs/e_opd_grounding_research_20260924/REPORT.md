# 从纯 E-OPD 到视觉 grounding 学习：调研与判别方案

日期：2026-09-24。状态：文献调研、现有代码核查、已有训练记录的 CPU 审计完成；本文提出的方法尚未完成新的模型训练验证。

本轮研究边界已由用户确认：允许扩大可训练范围，完整 bbox 定位质量为主指标，视觉证据使用为机制指标，CoT 长度为辅助指标。以当前**纯 E-OPD**为起点，不恢复 SFT，也不使用 SFT checkpoint。保持既有实验结果和评估流程。

## 1. 判断：不是放弃坐标输出，而是增加约束它的证据

建议主线是：**让早期教师提供有视觉依据的定位指导，用完整框的几何结果约束更新，再检验学生是否随图像中的真实变化作出正确的位置变化。**

当前结果还不能说明“坐标分布蒸馏学不会 grounding”。只要教师分布包含正确的图像—位置映射，输出蒸馏也可能传递这种能力。现有设置同时受教师质量、损失覆盖范围、可训练容量和任务指标四个因素制约，不能把负结果全部归到 token 表示。

需要区分三层证据：

1. **输出更像教师**：KL 下降。它只证明局部条件分布更接近。
2. **框更正确**：未见图像的随机 mean IoU 上升。这才是主要任务收益。
3. **正确地使用视觉证据**：目标移动时框跟随移动，遮挡相关区域比遮挡匹配背景更影响定位，背景干预不会任意改变答案。它比“注意力更高”“图像去掉后概率变化更大”更接近用户说的“学会怎么 grounding”。

工作性假设是：当前 E 教师提供的有效信息没有充分转化为整框几何学习；监督遗漏部分坐标结束决策、教师视觉信息与文本先验混合、末层适配器容量有限，都值得竞争性检验。尚无证据把其中任何一个定为唯一原因。

## 2. 现有纯 E-OPD 的证据与新发现

### 2.1 已观察结果

统计来自冻结 step-200 checkpoint 的已有 dev 结果：60 张图，每图一条共同冻结轨迹，每条轨迹四次随机出框，训练组有三个 seed。Base-L 是共同基线，不是三个独立训练的模型。

| 系统 | 随机 mean IoU | 相对 Base-L | 图像配对 bootstrap 95% CI |
|---|---:|---:|---|
| Base-L | 0.277817 | — | — |
| 纯 E-OPD | 0.275707 | -0.002110 | [-0.007718, +0.003163] |

这支持“当前 E-OPD 没有显示稳定提升”，不支持“已证实显著损害”。本轮不把旧 SFT+OPD 分数混入方法判断。dev 用于过开发，不能替代独立确认。

现有错误案例包含正确实体下的边界不完整、少数随机框落到其他区域、反向框；也包含原推理先选错实体和疑似标注对应问题。后两类不能被统一解释为几何漂移。详见 [既有案例报告](../../outputs/research_experiments/mmgcot_timeline_training/pure_opd_v2/analysis/ERROR_CASES.md)。

### 2.2 当前算法实际上能更新什么

- Qwen3.5-0.8B，只有第 23 层 Query-only rank-8 适配器更新，共 24,576 参数。
- 原始推理和 v3p5 目标描述固定；学生是完整历史 L，教师是早期 25% 前缀 E，双方共享晚期目标描述。
- 教师固定为起点模型，按学生实际采样的原始 bbox token 前缀评分。
- 只对实际生成的数字 token 计算完整合法 support 的 reverse-KL。
- 没有整框奖励、视觉干预、attention 蒸馏、过程学习或 CoT 参数更新。

因此“仅有输出监督”和“仅允许非常窄的末端更新”在现有实验中没有分离。

### 2.3 新的可复现发现：坐标结束决策覆盖不完整

从三个纯 E run 的原始 `rollouts.jsonl` 重算得到：

| 统计量 | 数量 |
|---|---:|
| 训练出框记录 | 9,600 |
| 合法 support 同时包含数字与坐标结束符的位置 | 74,390 |
| 其中已计算 KL 的位置 | 69,757 |
| 其中未计算 KL 的位置 | 4,633（6.23%） |
| 至少含一次这类未监督决策的出框 | 3,839（39.99%） |

例如某条原始记录的前缀是 `741,11`，合法下一 token 为逗号或 0–9。学生选了逗号，得到第二个坐标 11，而不是继续写成 110–119。该位置 `numeric_mask=False`，保存的教师 logits 为 `None`。代码在 `score_teacher` 与 `backward_opd` 中均跳过该位置。

**需要精确理解：**如果同一类位置实际采样的是数字，当前完整 support KL 已经包含对逗号概率的约束；不是“逗号概率从未受训练”。遗漏发生在实际采样结束符的决策位置。这也意味着监督选择依赖本次采样动作，而不只依赖之前的状态。

这符合旧协议，不把它追认成训练实现违规。它是一个值得单独比较的协议选择。40% 不是错误率，更不代表 40% 样本能被修复；这些记录包含同图多次访问。

建议对照：保持教师、参数量、reverse-KL、grammar 不变，把监督位置改成**由 grammar 前缀状态定义的坐标决策位置**。数字和“是否结束当前数字”都包括；纯闭合标签可以仍不监督。坐标末端 `]` 及含它的合并 token 同样要处理，不能只硬编码逗号。

审计脚本：[audit_existing.py](audit_existing.py)。结果及输入 SHA256：[existing_evidence.json](existing_evidence.json)。本次只读审计在 tmux `eopd_research_cpu_0924` 完成。

以下优先依据论文原文与作者仓库；2026 年新稿按 arXiv 版本阅读，不凭搜索摘要擅自标为已录用。表中“可借鉴”是迁移判断，不是论文已经证明了我们的 bbox 任务。

| [TRACE，Wang 等，2026](https://arxiv.org/html/2605.10194v1) | 不同推理片段采用不同蒸馏/强化信号 | 支持分类型监督；依赖关键片段识别，不能把其数学推理标签直接搬来 |

| [MedGround-R1，Xu 等，2025](https://arxiv.org/html/2507.02994v1) | 空间/语义奖励与带框推理 | 支持整框反馈路线；医学领域和推理格式与本任务不同 |

| [UniVG-R1，Bai 等，2025](https://arxiv.org/abs/2505.14231) | 复杂 grounding 的推理与规则奖励训练 | 该工作使用 SFT 冷启动，不能据此要求我们必须重新加 SFT |

| [GKD，Agarwal 等，2023/ICLR 2024](https://arxiv.org/abs/2306.13649)；[DeepSeekMath，Shao 等，2024](https://arxiv.org/abs/2402.03300) | 在线蒸馏与 GRPO 的基础 | 用于明确采样策略、条件分布和奖励优化的区别 |

阅读范围：主要相邻方法核查到方法章节；Ground-R1、UniVG-R1 和基础方法在本轮主要核对摘要/定义，未重做其结果审计。没有把这些论文的数值提升外推到 Qwen3.5-0.8B。

**新颖性判断：**“视觉正负视图＋OPD”“不同 token 权重”“OPD＋GRPO”“attention 蒸馏”都已有直接先例。更有价值的研究空间是：**在同一实体、不同推理前缀下，把早期视觉响应迁移到末端，并用坐标结束决策、整框质量和图像变换响应证明它学到的是定位行为。**这只是候选主张，需要与 R 条件及上述方法直接比较，不能现在声明首次。

## 4. 想法一：视觉干预可用，但视觉敏感不等于几何正确

保留既有 E 教师、原图尺寸、问题、晚期目标描述和学生原始 bbox 前缀。为同一个预测位置构造：

\[
q^+_j(v)=p_{\theta_0}(v\mid I,q,r_{\le k},d,a_{<j}),\quad
q^-_j(v)=p_{\theta_0}(v\mid I^-,q,r_{\le k},d,a_{<j}).
\]

这里 \(I^-\) 是内容被模糊或遮挡的图像，保留相同画布和视觉 token 布局。**不是删除 image token**：删除会同时改变上下文长度和位置条件。

必须从受干预图片重新计算视觉特征和前缀缓存。复用原图 KV 后再声称“去图”是无效干预。固定原来的 \(r,d\) 是为了测量在既有文本条件下重新读取图像的边际作用；这些文本本身含有视觉信息，不能称它为“所有视觉信息的因果贡献”。

先实现一个透明的对比教师作为基线，而非立即发明复杂投影：

\[
A_j=\{v:q^+_j(v)\ge\rho\max_u q^+_j(u)\},\quad
s_j(v)=\mathbf1[v\in A_j]\,\operatorname{clip}(\log q^+_j(v)-\log q^-_j(v),-c,c),
\]
\[
\widetilde q_j(v)\propto q^+_j(v)\exp(\alpha s_j(v)).
\]

这是本报告提出的适配基线，借鉴 VCD 类对比，不冒称 VAD 原算法。采用有符号修正，既能增强也能抑制候选。保留原分布在全部合法 support 上的正质量，避免硬置零导致 reverse-KL 无穷大；合理候选外的相对比值不变，但全局归一化仍会改变其概率质量。实际数字 grammar 的候选很少，继续计算完整 support，不需要照搬大词表 top-K。

**为什么还不够：**一个错误候选也可能非常依赖图像。离线合成反例中，正确/错误框原概率是 0.7/0.3，去图后是 0.95/0.05；按一次视觉比值放大后，正确框概率反而变成 0.223。这不是模型实测，而是证明“更依赖图像”不足以推出“更正确”。

因此先看相同学生前缀下的完整框续写 IoU，再看 KL/熵。还需一个**相同强度的普通分布锐化对照**，排除收益只是来自更低温度；局部干预需要同面积背景遮挡对照，排除普遍的分布外破坏。全图模糊只是容易实现的第一种退化，不能据此声称精确定位了关键区域。

裁剪教师作为后续路线：先保留全图坐标系，使用全图＋辅助 crop，并明确 crop 在原图的位置。仅在 crop 内输出相对坐标再直接蒸馏原图坐标会错位。训练 GT 定位出的 crop 是特权空间监督，不能描述成无标签教师。

## 5. 想法二：把“怎么知道”变成可以测量的响应

### 5.1 优先路线：匹配视觉干预响应

令 `clr` 为在共同合法 support 上对 log-probability 去均值。早期教师的视觉响应定义为：

\[
u^E_j=\operatorname{clr}(q^+_{E,j})-\operatorname{clr}(q^-_{E,j}).
\]

对晚期学生同样计算 \(u^S_j\)，在相同原始 bbox 前缀上加入：

\[
\mathcal L_{\rm response}=\frac1{|D|}\sum_{j\in D}
\frac{\|u^S_j-\operatorname{sg}(u^E_j)\|_2^2}{|\Omega_j|}.
\]

\(D\) 使用前缀决定的坐标决策集合。教师全部 detach，学生原图和退化图两次评分均允许梯度。这直接教学生：**这部分视觉证据被拿走时，哪些位置候选的相对支持应变化。**它不要求隐藏向量逐维一致，也不需要教师写一段可能事后编造的解释。

这个损失不能单独使用：学生可能学到相同敏感性却保持整体坐标偏移，也可能复制教师对无关干预的脆弱性。它需要任务质量约束，并比较相关/背景干预的差别。它与 VAD 的“重建目标分布”是不同的实验变量，不应第一轮同时加上。

一个与时间线最相关的额外诊断是比较 \(u^E-u^{\mathrm{base\_L}}\)：早期与冻结末端教师的视觉响应到底差在哪些坐标决策上？若 E 的响应不比 L 更有用，就缺少“迁移早期过程”的前提。`base_L` 使用起点参数、完整推理和目标描述，保持与旧实验“不带目标描述”的 L0 分支区分。

### 5.2 Attention 蒸馏作为第二路线

Reinforced Attention Learning 提供了直接参考。但我们的 E/L 文本历史长度不同，不能对完整 attention 行逐位置 KL。可以先仅取双方共享、顺序相同的原图 patch，分别记录：视觉 attention 总质量、视觉内部的归一化空间分布，再蒸馏对应分布。视觉权重增加和选择正确区域是两件事。

选中的层/头必须先通过区域遮挡响应检验。视觉注意力看起来集中并不自动意味着那里决定了 bbox。Qwen3.5 的 GDN 层也不能被当成标准 full-attention 层直接读取同一种矩阵。先研究 full-attention 层，保留门控与实际输出效应。

对论文公式也应独立检查：单独使用“优势×当前/旧 attention 的散度”时，如果两者起始相同，散度在相等处分布梯度为零；不能仅凭该表达式就认定得到标准 GRPO 的动作采样梯度。本文优先借鉴其 attention 蒸馏接口，而不未经验证照搬全部优化解释。

### 5.3 等变性比“更敏感”更有判别力

把整张图以已知比例缩放并放入带 padding 的画布，目标框应按已知仿射变换 \(T\) 改变：\(B(TI)\approx T(B(I))\)。需要同时看变换后 GT IoU；只看一致性会被稳定的错误框骗过。

第一版只使用完整保留图像内容的平移/缩放，不用可能改变“左边第二个”指称的镜像。变换后重新生成该视图的冻结推理；原图 CoT 可能含坐标，不能原封不动带入变换视图当作干净等变性实验。教师/学生在每个视图内部仍共享该视图的同一推理与描述。目标身份改变的样本保留在全队列，另报同实体分析。

训练扩展可比较推前分布 \(T_\#P(B\mid I)\) 与 \(P(B\mid TI)\)，在框空间计算距离，而不是把镜像/平移前后数字 token 当成同一目标。教师框错误会被一致性传播，故等变性先用于诊断，再决定是否进入损失。该路线属于从 EquiSD 等对称性监督思想向 bbox 的迁移建议。

## 6. 想法三：按几何作用分监督，避免按字符外观划分

| 对象/决策 | 建议监督 | 原因 |
|---|---|---|
| 数字继续/结束，包括逗号与末端 `]` | 完整 support OPD，并受整框奖励 | 决定坐标值及位数，是几何动作 |
| 纯格式闭合标签 | grammar；必要时单独格式监测 | 通常不承载位置学习 |
| 完整 bbox | IoU 奖励/框空间比较 | 连接四个坐标，惩罚反向、过小、错位框 |
| 实体与关系选择 | 后续独立的语义/过程奖励 | 当前被冻结，不能假装已有优化 |
| 可验证的视觉证据引用 | 干预响应或空间注意力监督 | 给“看哪里、根据什么改变判断”可检验含义 |
| 冗余语言/CoT 长度 | 先监测；准确性稳定后单独做效率约束 | 首轮加短链奖励会混淆定位和长度效果 |

不要简单给百位、十位、个位按 100:10:1 加权。299→300 只移动 1 个坐标单位，却改变三位字符；300→900 改一个字符却移动 600。字符差异不是几何距离，首位数字还存在可变位数问题。

更强的框空间蒸馏可以对有限候选完整框做几何排序，或对坐标值分布做 CDF/Wasserstein 比较。必须先从完整数值候选构造分布，不能把十个 digit 概率直接当成十个有固定距离的坐标值。候选集缺失正确框时，这类损失同样无法凭空恢复目标。

## 7. 想法四：Visual-OPSD 能借什么，CoT 缩短应怎样理解

Visual-OPSD 的教师拥有中间视觉思考图，学生在原始图像和问题上生成文本完成；这里“text-only”指不再生成中间图，不是没有输入图像。方法在学生轨迹上做 JSD，并报告省掉 diffusion 后的显著延迟收益。[论文](https://arxiv.org/html/2606.18974v1)；[作者实现](https://github.com/TiezMind/Visual-OPSD/tree/main/scripts/visual_opsd)。

对我们最有用的是：为教师构造有价值的额外视觉条件；用真实视觉信息与噪声对照证明监督来源；把教师指导落在学生实际到达的前缀上。**不能据此预测我们的文本 CoT 必然缩短。**我们的 0.8B 路径没有该中间图 diffusion 开销，当前冻结 CoT 也根本不会因末端 OPD 而改变长度。

以后开放推理训练，再同时报告 mean IoU、自然结束比例、文本 token 数、图像处理成本和端到端时间。短一些但定位更差不是效率收益；通过截断导致“变短”也须单列。

## 8. 想法五：E-OPD＋GRPO 是最直接的任务连接

推荐采用**原模型起点、无 SFT 项**的混合目标：

\[
\mathcal L=-\mathcal J_{\rm GRPO}(R_{\rm box})+\lambda\mathcal L_{\rm E\text{-}OPD}.
\]

这里 GRPO 提供“哪些完整框更好”，OPD 提供每一步的密集指导。该组合本身已有 dGRPO 先例，不能作为唯一创新点。

第一版保留普通 E 教师，不同时引入视觉修正和 attention loss。每个 L 上下文采样 \(G=8\) 个当前学生 bbox，temp=1、完整 grammar support，保存旧策略 log-probability；奖励取有效框的连续 IoU，非法/未完成框为 0，不修复、不重采样到成功。GT 只进入奖励函数，不进入教师和模型 prompt。

**已有记录支持先试连续 IoU 奖励。**对三个纯 E checkpoint 的 dev 四次随机出框分组检查，每个 seed 的 60 组中分别有 56、58、58 组存在 IoU 差异；奖励全相同的组分别只有 4、2、2 组，均为全零。因此这批记录没有显示“多数组完全没有相对奖励”的障碍。它不是训练时 G=8 的实测，需要训练中继续记录。

同一批记录，按 GT 从每组四框选最好一个，平均 IoU 约为 **0.4443**，而正常四次平均为 **0.2757**。这只是使用 GT 的 oracle best-of-4，不能当成部署分数或可达到的训练上界；但它表明已有采样中有较好的框，奖励训练具有可利用的组内质量差异。该诊断使用完整 60 图，没有挑选成功案例。

按同上下文组计算相对优势。若组内奖励全相等，RL 优势设 0 并记录，OPD 仍可提供更新。不要为了避免零优势而删除这些组或无限补抽。先测连续奖励下零方差组的真实比例；只有它构成瓶颈，才单独比较 GIoU/中心距离等密集几何奖励，并保留 IoU 为主评估指标。

GRPO 的概率比、OPD 的归一化与采样必须共享 grammar 条件分布；不能采样时 mask、反传时使用未 mask 的全词表概率。奖励信用覆盖所有有意义的 bbox 动作，包括结束坐标的动作。均按样本/组归一化，再对 batch 平均。

**关于“不要 SFT”：**用 GT 计算 IoU 奖励不是 GT 坐标 teacher-forcing NLL；本建议不恢复后者。但它依然是有标签的奖励训练，不能标成完全无监督。

不默认额外加 reference KL：E-OPD 已经提供一个教师约束；若另加，必须作为独立系数记录。也不立即增加格式奖励，当前 grammar 已保证大部分语法格式。

必须保留纯 GRPO 对照：若混合方法只比 E-OPD 好，却不比 GRPO 好，证据支持奖励训练有效，尚不支持早期教师增加了价值。

## 9. 如何放宽可训练范围而不混淆原因

建议先区分两个梯度范围，教师仍固定：

- **A0：**现有第 23 层 Query-only，作为精确的容量对照。
- **A1：**第 19、23 两个 full-attention 层的 Query/Value/Output 低秩适配器，先 rank=8；Query 仍只改各 head 的 Query 分量，不改 gate。视觉编码器保持冻结。参数量运行前实际打印，不能沿用 24,576。

这不是声称两层足够，而是一个小而可解释的“允许更多视觉读取和整合”的改动。先固定自然轨迹文本，允许学生在评分时用当前参数重新编码它；因此测试的是定位整合能力，CoT 生成策略尚未优化。

对应推理接口也应一致：冻结起点模型先生成自然推理和描述，A1 学生再开启适配器重放 L 上下文并生成 bbox。不能训练时用适配器重编码前缀、评估时却继续喂旧的关闭适配器缓存。额外重放成本计入完整流程耗时。

**缓存合同必须重写：**A1 的前层输出/Value 会影响下游 KV/GDN 状态；不能继续复用当前跨 optimizer-step 的冻结 L cache。教师缓存仍可复用，学生缓存按当前参数重算。若在多位置启用适配器，原来依赖末层 Query 特性的逐 token 独立 backward/detached-cache 做法也必须验证梯度完整性。图片干预还须建立每个视图独立的缓存。

先比较同一 E-OPD 损失下的 A0/A1，再在选定容量下比较损失。若 A1 单独就有效，说明容量是关键解释之一；不能把它计入新蒸馏信号的贡献。

只有当要学习实体重选或 CoT 效率时，才开放自然推理 token 的更新和重新 rollout。那时教师早期前缀、目标描述都随当前学生轨迹重建；旧冻结文本训练不能继续被叫作完整推理 on-policy。

## 10. 最小、可判别的自动探索顺序

### 第一段：利用旧产物和冻结模型确定瓶颈

已完成：代码/目标审计、9,600 条纯 E 出框的停止决策统计、基础反例验证。

下一项低成本模型诊断建议固定 32 张 train 图，按 seed 20260924 抽取，题型尽量均衡，不根据教师胜负筛选；dev 只用于随后方案比较，既有 Test-200/独立确认结果不参与方法选择。每图一条原冻结轨迹。

1. 普通 E 与有视觉对比的 E，比较自由出框和固定 Base-L 坐标前缀续写。每条件 4 draw。
2. 视觉退化先固定为保持画布的 16×16 下采样后上采样；明确这是粗细节干预，不是真正无视觉。附全均值图作为不同退化对照。对比系数先注册 `alpha=0.5,rho=0.1,c=2`，只做一个配置，不在这 32 图网格搜索。
3. 对相同学生前缀，记录数字/停止两类位置、支持集、KL、熵、视觉响应。加入事先给定温度网格的锐化对照，温度由独立校准上下文匹配平均熵，不看该 32 图 IoU。
4. 局部证据敏感性另用预固定网格遮挡；用 GT 只在分析时判断遮挡是否覆盖目标，给同面积背景区域作对照。它是机制审计，不把 GT mask 输入训练教师。

如果视觉差分大而 IoU 不升，视觉敏感不是当前可靠的教师增强信号；转向几何信用分配。若 E/R 的干预响应与续写收益相同，保留“历史清理/重新定位”解释，不预设早期独有优势。

### 第二段：先做两个小对照，再运行核心三组

小对照一：数字-only vs grammar-state 坐标决策监督；仅改变 mask，保持旧参数量/教师/目标。首先隔离损失覆盖范围。

小对照二：在同一坐标决策 mask 下 A0 vs A1；只改变可训练范围。若 A1 不值得其成本，后续用 A0，不为故事强行扩大模型。

在这些工程/方法边界冻结后，核心三组是：

| 组 | 目标 | 要回答的问题 |
|---|---|---|
| E-OPD | 普通 E 的坐标决策 KL | 更完整监督后的蒸馏基线 |
| GRPO | 连续整框 IoU 奖励 | 单靠结果反馈能否学会定位 |
| E-OPD＋GRPO | 同一 KL＋同一奖励 | 教师是否在奖励训练之外增加收益 |

三组同起点、同可训练层、同训练顺序、同组采样数与更新预算，无 SFT/warm start。先单 seed 短探索，固定共同配置后再三 seed、固定步数验证。比较时同时报告 GPU 时间与生成 token 量；同 optimizer steps 不等于同计算成本。预算和超参数应在真正启动前写入可执行配置；本文不把研究建议冒充已经启动的实验。

### 第三段：验证“学习了视觉证据使用”的额外价值

在上一段稳定基线上，分别加一个新变量：视觉目标重建，或视觉响应匹配。attention 蒸馏和等变训练先作为备选，不同时加入。

至少报告：原图随机 mean IoU、贪心结果、低 IoU 尾部、无效框率、变换后 IoU、框变换一致性、相关/背景遮挡差别、同实体子集。身份标签只用于解释，不改全队列分母。

| 观察 | 解释 |
|---|---|
| 补齐停止决策后尾部改善 | 输出决策监督覆盖是瓶颈之一 |
| 只扩大适配器已改善 | 当前容量限制重要，不能归功于新教师 |
| GRPO 与混合都有效，二者接近 | 整框奖励有效；E 的额外收益未建立 |
| 混合优于 GRPO、E，并改善视觉干预/变换表现 | 支持教师指导与几何反馈互补 |
| 图像敏感性增强、正确 IoU 不升 | 学到了响应或脆弱性，未建立有效 grounding |
| 只在固定历史下有效，重新生成推理失效 | 条件式末端修复有效，完整流程迁移未建立 |
| 文本更短但 IoU 降低 | 性能/长度权衡，不当作免费效率提升 |

## 11. 最终建议与研究主张

优先顺序是：**补齐坐标决策监督的对照 → 分离可训练容量 → E-OPD / GRPO / 两者结合 → 在胜出基线上加入视觉干预响应约束。**

其中最有研究价值的候选机制是“视觉证据响应＋整框几何反馈”，最容易先得到清晰结论的是“E-OPD＋GRPO”。两者不必在第一次训练就合并。

潜在主张应写为：**在同一目标条件下，早期教师对视觉证据变化的定位响应可以迁移给末端学生；几何奖励使这种迁移落实为未见图像上完整框质量与变换响应的改善。**当前只是待验证假设。若 R 教师同样有效，主张应退回“视觉证据指导的历史条件蒸馏”，而不硬保留早期时间位置的独特性。

继续保留反向可能：教师没有稳定优势，奖励梯度与错误目标描述冲突，模型已有视觉特征不足，或当前数据/目标对应噪声限制性能。发现这些情况后应更新解释，不追加筛选把它们藏起来。

本轮交付的是可追溯的研究判断与分阶段判别路线；新增模型训练收益尚待检验。
